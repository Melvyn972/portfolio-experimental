## Assets 3D (maison / pipeline procédural)

Tous les modèles runtime dans `/public/models/*.glb` sont générés par `scripts/generate-assets.mjs` — géométrie stylisée méditerranéenne **CC0 maison**, un seul langage low-poly premium :

| Fichier | Rôle |
|---------|------|
| `roadster.glb` | Cabriolet Méditerranée (marque fictionnelle) |
| `explorer.glb` | Avatar piéton |
| `belvedere.glb` | Structure belvédère (pierre, verre, bois) |
| `maison.glb` | Maison / Atelier |
| `studio.glb` | Studio projets |
| `phare.glb` | Phare — destination finale |
| `stone-wall.glb` | Murets de pierre |
| `pine.glb` / `olive.glb` / `cypress.glb` / `bougainvillea.glb` | Végétation |
| `rock-a/b/c.glb` | Rochers |
| `bench.glb` / `carnet.glb` / `lamp.glb` / `plinth.glb` | Props |

Aucun asset Sketchfab / Meshy / Poly Haven n’est embarqué dans cette build. Si des packs CC0 externes sont ajoutés plus tard, documenter ici licence + URL + auteur.
